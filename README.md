# СМП МАРКО — Москва

Презентационный сайт на Next.js для московского региона.

## Запуск

```bash
pnpm install
pnpm dev
```

Откройте `http://localhost:3000`.

## Production

```bash
pnpm build
pnpm start
```

Перед публикацией подключите формы к CRM, почте или webhook и подтвердите актуальность реквизитов, телефонов и текста политики конфиденциальности.
