# СМП МАРКО

Сайт компании на Next.js и отдельная административная панель на Keystatic.

## Структура

- Корневое приложение — публичный статический сайт.
- `cms/` — серверная административная панель.
- `cms/content/` — редактируемые объекты, статьи, новости и контакты.
- `public/uploads/` — фотографии, загруженные из панели.
- `scripts/sync-cms-content.mjs` — подготавливает контент для публичной сборки.

Админка сохраняет изменения в GitHub. Новый коммит автоматически запускает
пересборку публичного сайта на Render, поэтому данные не зависят от временной
файловой системы хостинга.

## Публичный сайт

```bash
pnpm install
pnpm dev
```

Перед каждой production-сборкой команда `pnpm content:sync` формирует
`app/generated-content.ts` из файлов в `cms/content`.

## Административная панель

Локальный запуск:

```bash
pnpm install
pnpm cms:dev
```

Панель откроется на `http://localhost:3001/keystatic`. В локальном режиме
изменения записываются прямо в `cms/content`.

На Render панель запускается отдельным Node.js Web Service из `render.yaml`.
Для production-режима нужны переменные из `cms/.env.example` и GitHub App,
имеющий доступ к репозиторию `useral4/smp-marko`.

Пользователь с правом записи в репозиторий входит через GitHub и может:

- добавлять и скрывать объекты, статьи и новости;
- менять порядок карточек;
- загружать главную фотографию и галерею объекта;
- редактировать телефоны, адрес, почту, карту и ссылки на соцсети.

## Первичное заполнение

Команда ниже предназначена только для восстановления исходного набора данных:

```bash
node scripts/seed-cms-content.mjs --force
```

Она перезаписывает управляемый контент, поэтому в обычной работе её запускать
не нужно.
